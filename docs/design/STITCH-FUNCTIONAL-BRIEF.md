Create one desktop web application screen for Styio Community, a private
coordination console for the Styio ecosystem. The product idea is that
cross-repository decisions should be explicit, traceable, and ready for
execution. A human decision is the source of authority, while repository issues,
pull requests, adapters, and agents are downstream projections of that decision.
The screen should let a maintainer review the current decision, write execution
notes, approve or reject the decision, and dispatch approved work to the next
repository adapter. It needs to support a queue of decision records, selecting a
record, showing title, status, route, short summary, up to three key facts,
execution notes, approve, reject, dispatch, recent history, dispatch result,
and creating demo records for a syntax change and an IDE capability gap.
